## 1. 设计原则

### 1.1 核心设计理念

| 原则 | 说明 |
|------|------|
| **聚焦内容** | 学习是核心，UI 应该后退。大面积留白 + 一张卡片 = 注意力锁定 |
| **物理直觉** | 按钮像真实按钮一样可以被「按下」，卡片有明确的边界和触感 |
| **色彩引导** | 页面灰白为主，只有操作和反馈才用高饱和色，确保用户视线不被分散 |
| **一笔一画有意义** | 不用装饰性元素。每条线、每个色块都有功能性目的 |

### 1.2 设计参考与偏离

```
Duolingo 参考点             本设计决策
─────────────────────────────────────────
粗圆角边框                ✅ 保留（2px #E5E5E5 + 16px 圆角）
按钮带底边按压感           ✅ 保留（3-4px 同色深底边 + translateY 反馈）
大面积留白                ✅ 保留（#F7F7F7 背景 + #FFFFFF 卡片）
吉祥物（猫头鹰）           ❌ 移除
游戏化（宝石、生命值）      ❌ 移除
进度动画和音效             ❌ 移除（保留 SRS 进度条作为核心反馈）
Duolingo 绿色主题色        ❌ 不采用，改用 WCAG AA 合规的蓝色系
```

## 2. 色彩系统

### 2.1 调色板总览

```
                    主行动色                    次行动色
                   #2264D1                    #0D9488
               （深蓝·行动/正确/进度）       （深青·链接/次要操作）
                     ████                      ████

    主背景               次背景               强调色
   #FFFFFF              #F7F7F7              #D97706
 （卡片内部）           （页面底色）         （提醒/高亮/打卡）
    ████                 ████                 ████

    错误色               主文本               次文本
   #B91C1C              #4B4B4B              #AFAFAF
 （错误/删除）          （标题/正文）         （辅助/禁用）
    ████                 ████                 ████
```

### 2.2 颜色详细规格

| 颜色角色 | 色值 | 用途 | 白底对比度 | 白字对比度 |
|----------|------|------|------------|------------|
| **主背景色** | `#FFFFFF` | 卡片内部、核心学习区、输入框背景 | — | `#4B4B4B` 8.2:1 ✅ |
| **次背景色** | `#F7F7F7` | 页面大背景，衬托白色卡片 | — | `#4B4B4B` 7.8:1 ✅ |
| **主行动色** | `#2264D1` | 核心操作按钮、正确反馈、进度条 | 5.3:1 ✅ | 4.6:1 ✅ |
| **主行动色深底边** | `#1A4FA8` | 主按钮的 4px 底部色条 | 6.7:1 ✅ | — |
| **次行动色** | `#0D9488` | 次要按钮、文字链接、标签页激活态 | 5.1:1 ✅ | 4.1:1 ✅ |
| **次行动色深底边** | `#0A7369` | 次按钮的 4px 底部色条 | 6.3:1 ✅ | — |
| **强调色** | `#D97706` | 连续打卡数字、关键数据高亮、警告 | 4.2:1 ✅ ⚠️ | — |
| **错误色** | `#B91C1C` | 答错状态、删除按钮、校验失败 | 6.2:1 ✅ | 5.2:1 ✅ |
| **主文本色** | `#4B4B4B` | 标题、正文、单词展示 | 8.2:1 ✅ | — |
| **次文本色** | `#AFAFAF` | 占位符、辅助说明、未选中状态 | 2.6:1 ⚠️ | — |
| **卡片边框** | `#E5E5E5` | 所有卡片的 2px 边框 | 1.4:1 | — |
| **进度条轨道** | `#E5E5E5` | 进度条未填充部分 | — | — |

> ✅ **全色对比度合规**：所有功能性颜色（按钮背景、错误色、主文本）在白色背景或白色文字上均达到 WCAG AA 标准。`#AFAFAF` 次文本仅用于 ≥14px 的辅助信息，符合大号文字 3:1 豁免。`#E5E5E5` 边框为非信息性装饰，无对比度要求。

#### 为什么选蓝色系而不是绿色系

| 维度 | 绿色（如 Duolingo #58CC02） | 蓝色 #2264D1 |
|------|---------------------------|-------------|
| 白字对比度 | 2.3:1 ❌ | 4.6:1 ✅ |
| 色觉障碍友好 | 红绿色盲难以分辨绿色和红色反馈 | 蓝红双通道清晰可辨 |
| 学习场景 | 绿色偏游戏/娱乐 | 蓝色偏专注/信任，适合学习工具 |
| 跨文化 | 绿色在中东/南美部分地区有宗教含义 | 蓝色全球通用，中性安全 |

### 2.3 热力图色彩梯度

GitHub 风格贡献热力图使用主行动色的不同透明度层级：

| 层级 | 色值 | 含义 |

| 3（较多） | `#2264D1` | 16-30 个单词 |

## 3. 字体与排版

### 3.1 字体家族

| 角色 | 字体 | 备选 |
|------|------|------|
| **西语/英文标题 + 正文** | **Nunito** | 系统默认无衬线字体 |
| **中文标题 + 正文** | **系统默认黑体**（PingFang SC / HarmonyOS Sans / Noto Sans SC） | 系统默认圆体 |
| **等宽/数据数字** | Nunito (tabular-nums) | SF Mono |

```css
/* Google Fonts 引入 */
@import url('https://fonts.googleapis.com/css2?family=Nunito:wght@400;500;600;700;800;900&display=swap');

/* CSS 字体栈 */
font-family: 'Nunito', 'PingFang SC', 'HarmonyOS Sans SC', 'Noto Sans SC', 'Microsoft YaHei', sans-serif;
```

### 3.2 排版规格表

| 层级 | 字号 | 行高 | 字重 | 用途 | 示例 |
|------|------|------|------|------|------|
| **H1** | 24–28px | 1.3 | 800 (Extra Bold) | 页面核心标题 | 「今日复习」 |
| **H2** | 18–20px | 1.4 | 700 (Bold) | 模块标题、数据卡片标题 | 「累计单词」 |
| **Body** | 16px | 1.5–1.6 | 400/500 | 正文、单词展示、例句 | *el problema* |
| **Body Small** | 14px | 1.5 | 400 | 次要描述、标签文字 | 词性标注、来源 |
| **Caption** | 12–13px | 1.4 | 400 | 时间戳、辅助信息 | 「3 天前复习」 |
| **Button Text** | 16px | 1.2 | 700 | 按钮文字 | 「开始学习」 |
| **数字/数据** | 20–28px | 1.2 | 800 | 统计数据大数字 | 「120」 |

### 3.3 排版规则

- **行长限制**：正文每行不超过 65–75 个字符（约 38–42rem），保证西语阅读舒适度
- **段落间距**：段落之间 16px (1rem)
- **文字对齐**：正文左对齐，数字居中
- **连字符**：西语单词禁止连字符断词（`hyphens: none`）
- **溢出处理**：长单词用 `line-clamp-2` 或省略号

## 8. 动效规范

### 8.1 时长标准

| 动效类型 | 时长 | 缓动函数 |
|----------|------|----------|
| 按钮按下/弹起 | 100ms | `ease-out` |
| 卡片翻转 | 400ms | `ease-in-out` |
| 页面过渡 | 200ms | `ease-out` |
| Toast 出现/消失 | 300ms | `ease-out` |
| Modal 打开/关闭 | 200ms / 150ms | `ease-out` / `ease-in` |
| 进度条填充 | 500ms | `ease-out` |
| 列表项入场 | 200ms (stagger 50ms) | `ease-out` |
| Hover 颜色变化 | 150ms | `ease-out` |

### 8.2 动效细则

```
按钮按压：
  transition: transform 100ms ease-out, border-width 100ms ease-out
  :active → border-bottom-width: 0 + transform: translateY(4px)

卡片翻转：
  transform-style: preserve-3d
  .front { backface-visibility: hidden }
  .back  { backface-visibility: hidden; transform: rotateY(180deg) }
  .flipped .front { transform: rotateY(-180deg) }
  .flipped .back  { transform: rotateY(0deg) }

页面转场：
  路由切换: opacity 0→1, translateY(8px→0)
  注意: 尊重 prefers-reduced-motion

进度条增长：
  transition: width 500ms cubic-bezier(0.4, 0, 0.2, 1)

连续打卡升级：
  数字滚动 + 火焰图标放大 120% → 回弹至 100%
  animation: scale 1.2 → 1.0 (300ms) ease-out
```

### 8.3 减少动效 (prefers-reduced-motion)

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
