## 1. 产品概述

### 1.1 产品定位

一款面向西语初学者的 **PWA 单词记忆工具**，支持手动导入单词、闪卡背诵、间隔重复（SRS）复习。Web 端和手机端均可使用，一套代码覆盖全平台。

### 1.2 产品愿景

让西语初学者拥有一个**纯粹、高效、可定制**的记单词工具——不是另一个 Anki，而是一个更懂西语学习痛点（冠词、动词变位、真实例句）的专属工具。

### 1.3 核心差异化

| 对比维度 | Anki | 本工具 |
|----------|------|--------|
| 西语专属 | 通用卡片，需手动配置字段 | 原生支持冠词、词性、动词变位、同源/反义词关联 |
| 例句 | 需手动添加 | 导入时自动从词典/语料库抓取真实例句，标注来源 |
| 学习曲线 | 陡峭（插件、模板、参数配置） | 即开即用，零配置 |
| 平台 | 多端分离，同步需 AnkiWeb | PWA 一套代码，local-first 自动同步 |

## 2. 目标用户

### 2.1 用户画像

- **身份**：中文母语者，西语初学者（A1-B1 水平）
- **场景**：利用碎片时间背单词（通勤、午休、睡前）
- **设备**：手机为主，偶尔电脑
- **痛点**：
  - 现有工具不区分阴阳性、不展示定冠词
  - 例句是机器生成的，不自然
  - Anki 太复杂，不想折腾

## 3. 核心功能

### 3.1 单词卡片

#### 3.1.1 字段定义

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 西语单词 | 文本 | ✅ | 含定冠词（如 *el problema*、*la mano*） |
| 中文释义 | 文本 | ✅ | 支持多个释义，用分号分隔 |
| 词性 | 枚举 | ✅ | 名词(阴阳性标注) / 动词 / 形容词 / 副词 / 介词 / 连词 / 其他 |
| 例句 | 文本 | ❌ | 西语 + 中文翻译，含来源标注 |
| 发音音频 | 文件/URL | ❌ | 默认浏览器 TTS，可选真人发音 |
| 动词变位 | 结构化数据 | ❌ | 仅动词字段：现在时/过去时/虚拟式/命令式等不规则变位 |

#### 3.1.2 词性枚举

```
名词-阳性 (nm)     → el libro
名词-阴性 (nf)     → la mesa
名词-阴阳同形 (nc)  → el/la estudiante
动词 (v)           → hablar
形容词 (adj)        → bueno
副词 (adv)          → rápidamente
介词 (prep)         → para
连词 (conj)         → porque
其他 (other)
```

#### 3.1.3 例句来源标注

每条例句携带来源标签：

| 来源 | 说明 |
|------|------|
| 🏛️ 词典 | SpanishDict / WordReference / RAE |
| 📚 语料库 | Tatoeba / OpenSubtitles |
| ✍️ 手动添加 | 用户自己输入 |

导入单词时自动尝试抓取例句，失败则留空，用户可后续手动补充。

### 3.2 学习模式

#### 3.2.1 闪卡翻面模式

- 正面展示：西语单词 + 发音按钮
- 点击翻转：中文释义 + 词性 + 例句 + 动词变位（如有）
- 手势支持：左滑「不记得」/ 右滑「记得」
- 桌面端键盘快捷键：`←` 不记得 / `→` 记得 / `Space` 翻转 / `S` 星标

#### 3.2.2 SRS 间隔重复模式

- **算法**：SM-2 简化版（两档判断：记得 / 不记得）
- **交互**：看正面 → 脑内回忆 → 翻转 → 点「记得」或「不记得」
- **间隔自动计算**：
  - 新词首次：15 分钟后再次出现
  - 记得 ≥1 次：间隔 × 递增因子
  - 不记得：重置到最短间隔
- **每日复习队列**：系统自动生成当日待复习列表

#### 3.2.3 学习模式切换

| 模式 | 展示 | 用户操作 |
|------|------|----------|
| 西 → 中 | 看西语，回忆中文意思 | 默认模式 |
| 中 → 西 | 看中文，回忆西语拼写（含冠词） | 适合拼写训练 |
| 听音辨义 | 听发音，回忆中文意思 | 适合听力训练 |

### 3.3 导入功能

| 方式 | 场景 | 格式要求 |
|------|------|----------|
| 手动逐个添加 | 日常遇到的新词 | 表单填写（至少 西语+释义+词性） |
| 批量粘贴 | 从笔记/聊天记录粘贴 | 每行一个单词，Tab 分隔字段 |
| 文件导入 | 从 Excel/CSV 导入 | 自动映射列，预览后确认 |
| Anki 导入 | 从 Anki 迁移 | 解析 apkg 文件，映射字段 |

导入流程统一为：**选择来源 → 解析预览 → 确认导入 → 自动抓例句 → 完成**。

### 3.4 分组与标签

#### 3.4.1 来源分组（自动）

每次导入自动创建一个来源分组：

- 手动添加
- 文件导入：`文件名_导入日期`
- Anki 导入：`Anki牌组名_导入日期`

用户可重命名分组。

#### 3.4.2 自定义标签（手动）

用户可创建标签并给单词打标，如：

- `不规则动词`
- `高频词`
- `DELE A1`
- `虚拟式`
- `易混淆`

一个单词可以有多个标签。

#### 3.4.3 学习范围筛选

学习前可选择：
- 全部单词
- 指定分组
- 指定标签
- 仅星标
- 组合筛选（分组 ∩ 标签）

### 3.5 星标（生词本）

- 任何模式下可一键加星标 ⭐
- 独立的「星标单词」视图
- 支持集中攻坚：仅复习星标词

### 3.6 动词变位表

- 仅对词性为「动词」的单词展示
- 覆盖时态：现在时、简单过去时、过去未完成时、将来时、虚拟式现在时、命令式
- 区分规则动词和不规则动词
- 数据来源：内置规则变位表 + 不规则动词数据库

### 3.7 同源/反义词关联

- 系统维护关联关系表
- 查看单词详情时，自动展示同源词和反义词
- 示例：*bueno* ↔ *malo*（反义），*hablar* ↔ *hablante*（同源）

### 3.8 学习统计

#### 3.8.1 连续打卡天数 (Streak)

- 每天至少完成 1 次复习（≥ 5 张卡片）即算打卡
- 展示当前连续天数、历史最长连续天数
- 日历热力图：一眼看过往打卡情况

#### 3.8.2 学习统计面板

| 指标 | 说明 |
|------|------|
| 累计学习单词数 | 词库总数 |
| 已掌握单词数 | SRS 中状态为「熟练」（间隔 ≥ 30 天）的单词 |
| 学习中的单词数 | 处于 SRS 复习队列中的单词 |
| 今日已复习 | 今日完成复习的卡片数 |
| 记忆留存率 | 最近 100 次「记得」/ 100 × 100% |

### 3.9 导出功能

| 格式 | 包含内容 | 用途 |
|------|----------|------|
| CSV | 全部字段 + 学习状态 | 数据备份、Excel 分析 |
| Anki apkg | 字段映射为 Anki 卡片模板 | 迁移到 Anki |

### 3.10 账号与同步

#### 3.10.1 账号系统

- 邮箱 + 密码注册
- 邮箱验证（可选）
- 密码重置
- 登录态持久化（JWT + refresh token）

#### 3.10.2 云端同步

- **模式**：local-first（本地 IndexedDB 为主，云端为备份）
- **同步时机**：联网时自动后台同步，用户也可手动触发
- **冲突处理**：以最后修改时间（lastModified）为准，简单高效
- **首次使用**：可不注册直接使用，数据仅存本地；注册后启用云端同步

## 4. 数据模型

### 4.1 核心实体

```
Word（单词）
├── id: UUID
├── spanish: string           # 西语单词（含冠词）
├── chinese: string           # 中文释义
├── partOfSpeech: enum       # 词性
├── examples: Example[]      # 例句列表
├── audioUrl?: string        # 发音音频地址
├── conjugation?: Conjugation # 动词变位（仅动词）
├── tags: Tag[]              # 标签列表
├── groupId: UUID            # 所属来源分组
├── isStarred: boolean       # 是否星标
├── srsState: SrsState       # SRS 学习状态
├── createdAt: DateTime
├── updatedAt: DateTime
└── userId: UUID

Example（例句）
├── id: UUID
├── spanish: string          # 西语句子
├── chinese: string          # 中文翻译
├── source: enum             # 词典 / 语料库 / 手动
└── sourceDetail?: string    # 具体来源名称

Conjugation（动词变位）
├── wordId: UUID
├── present: TenseRow        # 现在时
├── preterite: TenseRow      # 简单过去时
├── imperfect: TenseRow      # 过去未完成时
├── future: TenseRow         # 将来时
├── subjunctive: TenseRow    # 虚拟式现在时
├── imperative: TenseRow     # 命令式
└── isRegular: boolean       # 是否规则动词

TenseRow（单时态变位）
├── yo: string
├── tú: string
├── él/ella/usted: string
├── nosotros: string
├── vosotros: string
├── ellos/ellas/ustedes: string

SrsState（SRS 状态）
├── repetitions: integer     # 连续「记得」次数
├── easeFactor: float        # 易度因子（默认 2.5）
├── interval: integer        # 当前间隔（天）
├── nextReviewAt: DateTime   # 下次复习时间
├── lastReviewedAt: DateTime # 上次复习时间
└── lastAnswer: enum         # 上次回答：记得/不记得

Group（来源分组）
├── id: UUID
├── name: string
├── source: enum             # manual / file / anki
├── createdAt: DateTime
└── userId: UUID

Tag（标签）
├── id: UUID
├── name: string
├── color: string            # 标签颜色
└── userId: UUID

User（用户）
├── id: UUID
├── email: string
├── passwordHash: string
├── streak: integer          # 当前连续打卡天数
├── longestStreak: integer
├── lastCheckinDate: Date
└── createdAt: DateTime

StudyRecord（学习记录）
├── id: UUID
├── userId: UUID
├── wordId: UUID
├── mode: enum               # flashcard / srs
├── direction: enum          # es→zh / zh→es / listening
├── answer: enum             # 记得 / 不记得
├── duration: integer        # 停留时间（秒）
└── createdAt: DateTime
```

### 4.2 关联关系

```
Word ──belongsTo──→ Group
Word ──hasMany──→ Example
Word ──hasOne──→ Conjugation
Word ──belongsToMany──→ Tag
Word ──hasOne──→ SrsState
Word ──hasMany──→ StudyRecord
Word ──hasMany──→ WordRelation (同源/反义词)

WordRelation
├── wordId: UUID
├── relatedWordId: UUID
└── relationType: enum       # cognate / antonym
```


## 8. 附录

### 8.1 关键第三方 API

| API | 用途 | 费用 |
|-----|------|------|
| SpanishDict (非官方) | 例句 + 释义 | 免费（有频率限制） |
| Tatoeba | 开源例句 | 免费 |
| WordReference | 词典查询 | 免费（非官方 API） |
| Web Speech API | TTS 发音 | 免费（浏览器内置） |

### 8.2 参考竞品

| 产品 | 优点 | 不足 |
|------|------|------|
| Anki | SRS 鼻祖，生态丰富 | 西语字段需手动配置，太复杂 |
| Quizlet | UI 好，学习模式多 | 例句为机器生成，非真实语料 |
| Memrise | 视频真人例句 | 内容不可自定义，无法导入自己的词库 |
| 墨墨背单词 | SRS + 中文用户友好 | 仅限英语，不支持西语 |

### 8.3 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 例句 API 不稳定/被封 | 核心功能不可用 | 多源备用 + 手动补充入口 + 例句缓存 |
| 浏览器 TTS 发音不准 | 用户体验差 | 后续接入 Forvo 真人发音 |
| Anki apkg 解析兼容性 | 部分牌组导入失败 | 只支持标准卡片模板，兼容测试 |
| 云端同步冲突 | 数据丢失 | 以 lastModified 为准 + 同步日志 |
