# 词典填充 SOP

> 词典文件：`packages/database/src/dictionary.ts`
>
> 每条记录包含：`article`（冠词）、`pos`（词性）、`chinese`（中文释义）、`definitionEs`（西语释义）、`examples`（例句数组）、`conjugation`（动词变位，可选）

---

## 一、词条格式

### 名词（阳性）
```ts
problema: {
  article: "el",
  pos: "NM",
  chinese: "问题；难题",
  definitionEs: "Cuestión que se trata de resolver.",
  examples: [
    { spanish: "Tengo un problema.", chinese: "我有一个问题。" }
  ],
},
```

### 名词（阴性）
```ts
casa: {
  article: "la",
  pos: "NF",
  chinese: "房子；家",
  definitionEs: "Edificio para habitar.",
  examples: [
    { spanish: "Estoy en casa.", chinese: "我在家。" }
  ],
},
```

### 动词
```ts
hablar: {
  article: "",
  pos: "V",
  chinese: "说话；讲（语言）",
  definitionEs: "Articular palabras; comunicarse oralmente.",
  examples: [
    { spanish: "Hablo español.", chinese: "我说西班牙语。" },
    { spanish: "¿Hablas inglés?", chinese: "你说英语吗？" }
  ],
},
```

### 形容词
```ts
bueno: {
  article: "",
  pos: "ADJ",
  chinese: "好的",
  definitionEs: "Que tiene bondad o calidad.",
  examples: [
    { spanish: "Es una buena idea.", chinese: "这是个好主意。" }
  ],
},
```

### 副词/介词/连词
```ts
muy: {
  article: "",
  pos: "ADV",
  chinese: "非常",
  definitionEs: "En grado sumo.",
  examples: [
    { spanish: "Es muy interesante.", chinese: "这非常有趣。" }
  ],
},
```

## 二、批量导入方法

### 方法1：用 ChatGPT / Claude 生成

发这段话给 AI：

```
请为以下西班牙语单词生成词典条目，格式为 TypeScript 对象字面量。
每条包含：article(冠词el/la/空)、pos(词性NM/NF/V/ADJ/ADV/PREP/CONJ)、
chinese(中文释义)、definitionEs(西语释义，一句话)、
examples(2条例句，格式{spanish:"...", chinese:"..."})

词性规则：
- 以 -ar/-er/-ir 结尾 → V
- 冠词 el → NM，冠词 la → NF
- 可兼作形/副的标注 ADJ 或 ADV

单词列表：[这里粘贴你要的单词，用逗号分隔]
```

然后把生成的代码贴到 `dictionary.ts` 的 `const DICT = {` 和 `};` 之间。

### 方法2：用脚本快速添加骨架

```bash
cd spanish-vocab-app
node -e "
const fs = require('fs')
// 单词列表（逗号分隔）
const words = 'perro, gato, sol, luna, mar, flor, pan, vino'.split(', ')
for (const w of words) {
  // 自动判断词性
  let entry = ''
  if (w.endsWith('ar')||w.endsWith('er')||w.endsWith('ir')) {
    entry = `  ${w}:{article:\"\",pos:\"V\",chinese:\"\",definitionEs:\"\",examples:[]},`
  } else if (w.endsWith('a')||w.endsWith('ión')||w.endsWith('dad')) {
    entry = `  ${w}:{article:\"la\",pos:\"NF\",chinese:\"\",definitionEs:\"\",examples:[]},`
  } else {
    entry = `  ${w}:{article:\"el\",pos:\"NM\",chinese:\"\",definitionEs:\"\",examples:[]},`
  }
  console.log(entry)
}
"
```

然后手动补全 `chinese`、`definitionEs`、`examples`。

## 三、手工填充优质数据的来源

| 来源 | 用法 |
|------|------|
| **Wiktionary** | 打开 `https://es.wiktionary.org/wiki/[单词]`，抄 `sustantivo masculino` 和第一条释义 |
| **西班牙语助手** | 查 `https://www.spanishdict.com/translate/[单词]` |
| **WordReference** | `https://www.wordreference.com/es/en/[单词]` |
| **Tatoeba** | `https://tatoeba.org/en/sentences/search?query=[单词]&from=spa` 找真实例句 |
| **ChatGPT/Claude** | 一次性生成 20-50 个词条的完整数据 |

## 四、词性对照表

| 缩写 | 含义 | 冠词 | 判断方法 |
|------|------|------|----------|
| `NM` | 阳性名词 | el | 以 -o/-or/-aje 结尾，或手查是阳性 |
| `NF` | 阴性名词 | la | 以 -a/-ción/-dad 结尾，或手查是阴性 |
| `V` | 动词 | 无 | 以 -ar/-er/-ir 结尾 |
| `ADJ` | 形容词 | 无 | 修饰名词，有性数变化 |
| `ADV` | 副词 | 无 | 以 -mente 结尾，或修饰动词 |
| `PREP` | 介词 | 无 | a/de/en/con/por/para/sin/sobre/entre... |
| `CONJ` | 连词 | 无 | y/o/pero/porque/que/si/cuando... |

## 五、填充优先级

1. **第一优先**：你自己正在学的单词 → 手工逐个写完整
2. **第二优先**：DELE A1/A2 词表 → 用 ChatGPT 批量生成 → 人工校对
3. **第三优先**：DELE B1/B2 词表 → 先用脚本生成骨架 → 逐步补全
